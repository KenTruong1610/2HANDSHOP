# ĐỒ ÁN HHHTQL - CỬA HÀNG 2HANDSHOP

Dự án này là một hệ thống mô phỏng hình thức quản lý 1 cửa hàng trực tuyến. Sản phẩm đầu ra của dự án là 1 hệ thống hoàn chỉnh có thể sử dụng các chức năng. 


## ✨ Tính Năng Nổi Bật
- **Quản trị viên:** Quản lý hệ thống cửa hàng.
- **Giao diện mua sắm:** Giúp người dùng lựa chọn sản phẩm mình muốn.
- **Đăng nhập / Đăng kí:** Giúp người dùng cá nhân hóa tài khoản của mình.
- **Thanh toán:** Giao dịch với khách hàng.
- **Liên hệ:** Giúp khách hàng xử lý sự cố.

### Lưu ý:
Đây là sản phẩm demo nên còn nhiều lỗi, nếu có lấy về cần chỉnh sửa để hoàn thiện báo cáo.
